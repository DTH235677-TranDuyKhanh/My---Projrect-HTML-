Biến đổi 3D trong CSS

  1. Biến đổi 3D CSS

    2. Thuộc tính CSS này transform áp dụng phép biến đổi 2D hoặc 3D cho một phần tử. Thuộc tính này cho phép bạn xoay, phóng to, di chuyển và làm biến dạng các phần tử.

    Di chuột qua các phần tử bên dưới để thấy sự khác biệt giữa phép biến đổi 2D và 3D

  2. Các hàm biến đổi 3D trong CSS

  4. rotateY
