Thư viện ảnh trong CSS

  1. Thư viện hình ảnh CSS

    2. Thư viện ảnh CSS là tập hợp các hình ảnh được hiển thị theo cách có tổ chức và thường có khả năng phản hồi trên trang web.

    Ở đây chúng ta sử dụng CSS để tạo thư viện ảnh:

    Hình 1: Danh lam thắng cảnh.
    Hình 2: Vịnh Hạ Long.
    Hình 3: Chùa Một Cột.

    Cấu trúc HTML cho một thư viện hình ảnh là:

    • Một phần tử chứa để bao bọc toàn bộ thư viện ảnh (giống như
      với class="gallery").
    • Một phần tử chứa khác cho mỗi hình ảnh (như div có class="gallery-item"), chứa thẻ img và có thể có phần mô tả.

  2. Thư viện ảnh đáp ứng CSS

    3. Ở đây chúng tôi sử dụng truy vấn phương tiện CSS để sắp xếp lại hình ảnh trên các kích thước màn hình khác nhau:

    • Nếu màn hình rộng hơn 768px - hiển thị bốn hình ảnh cạnh nhau
    • Nếu màn hình nhỏ hơn 768px - hiển thị hai hình ảnh cạnh nhau
    • Nếu màn hình nhỏ hơn 480px - xếp chồng hình ảnh theo chiều dọc (chiều rộng: 100%)
