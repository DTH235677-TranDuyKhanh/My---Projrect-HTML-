Giao diện người dùng trong CSS

  1. Giao diện người dùng CSS

    2. Trong chương này, bạn sẽ tìm hiểu về các thuộc tính giao diện người dùng CSS sau:

    • resize
    • outline-offset

  2. Thay đổi kích thước bằng CSS

    3. Thuộc tính này resizequy định liệu người dùng có thể thay đổi kích thước một phần tử hay không (và bằng cách nào).

    Thuộc tính này có thể có một trong các giá trị sau:

    • horizontal- Người dùng có thể thay đổi kích thước phần tử theo chiều ngang (chiều rộng)
    • vertical- Người dùng có thể thay đổi kích thước phần tử theo chiều dọc (chiều cao)
    • both- Người dùng có thể thay đổi kích thước phần tử theo chiều dọc và chiều ngang.
    • none- Người dùng không thể thay đổi kích thước phần tử

  3. CSS Resize - Chỉ thay đổi chiều rộng

    4. Ví dụ sau cho phép người dùng chỉ thay đổi kích thước chiều rộng của phần tử div:

    Let the user resize only the width of this div element.

    To resize: Click and drag the bottom right corner of this div element.

  4. CSS Resize - Chỉ thay đổi chiều cao

    5. Ví dụ sau cho phép người dùng chỉ thay đổi chiều cao của phần tử div:

    Let the user resize only the width of this div element.

    To resize: Click and drag the bottom right corner of this div element.

  5. CSS Resize - Cả chiều rộng và chiều cao

    6. Ví dụ sau cho phép người dùng thay đổi cả chiều rộng và chiều cao của phần tử div:

    Let the user resize only the width of this div element.

    To resize: Click and drag the bottom right corner of this div element.

  7. CSS Outline Offset

    8. Thuộc tính này outline-offsetthêm một khoảng trống giữa đường viền và cạnh/đường bao của một phần tử. Khoảng trống giữa phần tử và đường viền của nó là trong suốt

    Ví dụ sau đây chỉ định một đường viền nằm cách mép ngoài 15px:

    This div has a 4 pixels solid red outline 15 pixels outside the border edge.

    This div has a 5 pixels dashed blue outline 5 pixels outside the border edge.
