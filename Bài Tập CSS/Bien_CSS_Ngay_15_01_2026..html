Niến trong CSS

  1. Biến CSS - Hàm var()

    2. Hàm này var()được sử dụng để chèn giá trị của một biến CSS.

    Biến CSS có quyền truy cập vào DOM, điều này có nghĩa là bạn có thể tạo biến với phạm vi cục bộ hoặc toàn cục, thay đổi biến bằng JavaScript và thay đổi biến dựa trên các truy vấn phương tiện (media queries).

    Một cách hay để sử dụng biến CSS là khi bạn muốn quản lý màu sắc trong thiết kế. Thay vì sao chép và dán cùng một màu sắc nhiều lần, bạn có thể sử dụng chúng trong các biến.

  2. Khai báo biến trong CSS

    3. Biến CSS có thể có phạm vi toàn cục hoặc cục bộ.

    Biến toàn cục có thể được truy cập trong toàn bộ tài liệu, trong khi biến cục bộ chỉ có thể được sử dụng bên trong bộ chọn nơi nó được khai báo.

    Để tạo một biến toàn cục, hãy khai báo nó bên trong :root bộ chọn. :rootBộ chọn sẽ khớp với phần tử gốc của tài liệu.

    Để tạo một biến cục bộ, hãy khai báo nó bên trong bộ chọn sẽ sử dụng nó.

    Tên biến CSS phải bắt đầu bằng hai dấu gạch ngang (--) và phân biệt chữ hoa chữ thường!

    Cú pháp

    :root {
    --primary-bg-color: green; /* global scope */
    }
    .note {
    --note-bg: yellow; /* local scope */
    }

  3. Hàm CSS var()

    4. Hàm này var()được sử dụng để chèn giá trị của một biến CSS đã được khai báo.

    Cú pháp

    var(--name, value)

    Ưu điểm của việc sử dụng var()là:

    • Giúp mã nguồn dễ bảo trì hơn (đơn giản hóa việc cập nhật)
    • Giúp mã nguồn dễ đọc hơn (dễ hiểu hơn)
    • Giúp việc thay đổi giá trị màu sắc cho toàn bộ trang trở nên dễ dàng hơn.

  4. Ví dụ về biến CSS

    5. Ở đây, chúng ta khai báo hai biến toàn cục (--primary-bg-color và --primary-color).
