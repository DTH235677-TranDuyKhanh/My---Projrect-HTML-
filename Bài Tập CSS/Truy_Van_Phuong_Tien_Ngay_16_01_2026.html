Truy vấn phương tiện trong CSS

  1. Truy vấn phương tiện CSS

    2. Các truy vấn phương tiện CSS cho phép bạn áp dụng kiểu dáng dựa trên đặc điểm của thiết bị hoặc môi trường hiển thị trang web.

    Các truy vấn phương tiện CSS rất cần thiết để tạo ra các trang web có khả năng thích ứng với nhiều thiết bị.

    Quy tắc CSS này @mediađược sử dụng để thêm các truy vấn phương tiện (media queries) vào bảng định kiểu của bạn.

  2. Cú pháp truy vấn phương tiện

    3. Một truy vấn phương tiện bao gồm một loại phương tiện tùy chọn và một hoặc nhiều thuộc tính phương tiện, trả về giá trị true hoặc false.

    @media [not] media-type and (media-feature: value) and (media-feature: value) {
    /* CSS rules to apply */
    }

    Loại phương tiện là tùy chọn. Tuy nhiên, nếu bạn không sử dụng tùy chọn này , bạn cũng phải chỉ định loại phương tiện.

    Kết quả của truy vấn phương tiện là đúng nếu loại phương tiện được chỉ định khớp với loại thiết bị và tất cả các tính năng phương tiện đều đúng. Khi truy vấn phương tiện là đúng, các quy tắc kiểu tương ứng sẽ được áp dụng, theo các quy tắc xếp tầng thông thường.

    Ý nghĩa của các từ khóa "not" và "and " :

    not: Từ khóa tùy chọn này đảo ngược ý nghĩa của toàn bộ truy vấn phương tiện.

    và: Từ khóa này kết hợp một loại phương tiện và một hoặc nhiều tính năng phương tiện.

  3. Các loại phương tiện CSS

    4. Loại phương tiện tùy chọn chỉ định loại phương tiện mà các kiểu định dạng áp dụng. Nếu loại phương tiện bị bỏ qua, nó sẽ được đặt thành "tất cả".

    Value

    all

    print

    screen

    Description

    Used for all media type devices

    Used for print preview mode

    Used for computer screens, tablets, and smart-phones

  4. Tính năng đa phương tiện CSS

    5. Tính năng đa phương tiện chỉ định một đặc điểm cụ thể của thiết bị.

    Dưới đây là một số tính năng truyền thông thường được sử dụng:

    Value Description
    max-height Maximum height of the viewport
    min-height Minimum height of the viewport
    height Height of the viewport (including scrollbar)
    max-width Maximum width of the viewport
    min-width Minimum width of the viewport
    width Width of the viewport (including scrollbar)
    orientation Orientation of the viewport (landscape or portrait)
    resolution Screen resolution
    prefers-color-scheme User's preferred color scheme (light or dark)

  5. Ví dụ về truy vấn phương tiện

    6. Ở đây, chúng ta sử dụng media query để thay đổi màu nền của phần thân thành màu xanh lá nhạt nếu chiều rộng của khung nhìn là 480px trở lên:

    The media query is applied if the media type is screen, and the viewport width is 900px or more.

    Ở đây, chúng ta sử dụng media query để thay đổi màu nền của phần thân thành màu xanh nhạt nếu chiều rộng của khung nhìn nằm trong khoảng từ 480px đến 768px:

    The media query is applied if the media type is screen, and the viewport width is 900px or more.
