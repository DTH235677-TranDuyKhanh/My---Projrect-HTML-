Bộ chọn thuộc tính trong CSS

Bộ chọn thuộc tính CSS được sử dụng để chọn và định dạng các phần tử HTML có thuộc tính hoặc giá trị thuộc tính cụ thể hoặc cả hai. Các loại bộ chọn thuộc tính khác nhau được mô tả dưới đây.

  1. Bộ chọn [thuộc tính] CSS

    2. Bộ [attribute]chọn được sử dụng để chọn các phần tử có thuộc tính cụ thể.

    Ví dụ sau đây chọn tất cả các phần tử có thuộc tính target:

    HTML CSS JavaSrcipt

  2. Bộ chọn CSS [thuộc tính="giá trị"]

    3. HTML CSS JavaSrcipt

  3. Bộ chọn CSS [thuộc tính~="giá trị"]

    4. Bộ chọn được sử dụng để chọn các phần tử có giá trị thuộc tính chứa một từ cụ thể. [attribute~="value"] Ví dụ sau đây chọn tất cả các phần tử có thuộc tính tiêu đề chứa danh sách các từ được phân tách bằng khoảng trắng, một trong số đó là "flower":

  4. Bộ chọn [thuộc tính|="giá trị"] CSS

    5. Bộ [attribute|="value"]chọn được sử dụng để chọn các phần tử có thuộc tính cụ thể, giá trị của thuộc tính này có thể chính xác là giá trị cụ thể hoặc bắt đầu bằng giá trị cụ thể theo sau là dấu gạch ngang (-).

    Lưu ý: Giá trị phải là một từ hoàn chỉnh, có thể đứng riêng lẻ, như class="top", hoặc theo sau là dấu gạch ngang (-), như class="top-text".
