API lưu trữ web trong HTML

  1. HTML Web Storage là gì?

    • Với lưu trữ web, các ứng dụng có thể lưu trữ dữ liệu cục bộ trong trình duyệt của người dùng.
    • Trước HTML5, dữ liệu ứng dụng phải được lưu trữ trong cookie, được bao gồm trong mọi yêu cầu máy chủ. Lưu trữ web an toàn hơn và có thể lưu trữ cục bộ một lượng lớn dữ liệu mà không ảnh hưởng đến hiệu suất trang web.
    • Không giống như cookie, giới hạn lưu trữ lớn hơn nhiều (ít nhất 5MB) và thông tin không bao giờ được chuyển đến máy chủ.
    • Lưu trữ web được phân bổ theo nguồn gốc (theo tên miền và giao thức). Tất cả các trang, từ một nguồn gốc, có thể lưu trữ và truy cập cùng một dữ liệu.

  2. Đối tượng API lưu trữ web

    3. Lưu trữ web cung cấp hai đối tượng để lưu trữ dữ liệu trong trình duyệt:

    • window.localStorage- lưu trữ dữ liệu không có ngày hết hạn (dữ liệu không bị mất khi đóng tab trình duyệt)
    • window.sessionStorage- lưu trữ dữ liệu cho một phiên (dữ liệu sẽ bị mất khi đóng tab trình duyệt)

  3. Kiểm tra hỗ trợ API lưu trữ web

    4. Cú pháp để xóa mục localStorage "lastname" như sau:

    localStorage.removeItem("lastname");
